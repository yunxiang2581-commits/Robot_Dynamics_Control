## 已从公开资料确认的信息

- 项目名称：legged_control。
- 定位：基于 OCS2 和 ros-control 的 NMPC-WBC legged robot control stack。
- README 明确说明项目不再维护。
- OCS2 是 Optimal Control for Switched Systems 的 C++ toolbox。
- OCS2 支持 SLQ、iLQR、SQP、IPM、SLP 等算法。
