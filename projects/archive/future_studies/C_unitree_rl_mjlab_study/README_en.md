# C Unitree RL Mjlab Study

> Chinese version: [README.md](README.md)

This is Track C, the `unitreerobotics/unitree_rl_mjlab` reproduction and breakdown project.

The focus is MuJoCo, PPO, Train, Play, Sim2Real, observation, action, and reward. At the current stage, this project only provides structure and documentation entry points. It does not store training logs, policy weights, or large videos.
