## 6. 今日理解

- `wbc_speed_test` 不是完整 MuJoCo viewer demo，而是 non-viewer 的 WBC/PVT 数值计算与循环耗时 benchmark。
- 当前最小运行链路已经成立：Docker Ubuntu 22.04 + g++11 + R2 build artifacts + `wbc_speed_test` runtime PASS。
- `DataBus` 是 OpenLoong 控制链的核心共享状态对象，各模块通过它读写 `q/dq`、Jacobian、动力学项、步态状态、WBC 输出和 PVT 输出。
- `Pin_KinDyn` 对应学习主线里的 URDF -> FK -> Jacobian -> dynamics：它加载浮动基模型，计算 Jacobian、frame pose、质量矩阵、重力项和非线性项。
- `WBC_priority::computeDdq()` 负责优先级任务下的期望 `delta_q/dq/ddq`，`computeTau()` 负责接触力/关节力矩 QP。
- `PVT_Ctr` 是关节级输出层：用 `Kp/Kd`、期望位置/速度/力矩、低通滤波和限幅计算电机输出力矩。
- `datalog.log` 目前主要记录固定输入状态和 loop runtime，不记录 WBC 的 `qp_status`、`wbc_tauJointRes`、`wbc_FrRes`。
