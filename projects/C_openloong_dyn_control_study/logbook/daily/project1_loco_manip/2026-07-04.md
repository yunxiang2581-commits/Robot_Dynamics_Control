## 10. T5-D2：原地踏步 + 前平举掌心向上 + 右手 6-DoF 位姿保持

### 10.1 失败根因

最初直接把 `OPENLOONG_T5_POSTURE=1` 带进 `OPENLOONG_T4_IN_PLACE=1` 原地踏步时会摔倒：

- 默认 `OPENLOONG_T5_LOCK_COUNT=4000`：锁定时机器人已经进入踏步，手目标锁到了坏姿态附近，随后位置误差进入米级。
- 早锁 `OPENLOONG_T5_LOCK_COUNT=1000`：1s 锁住时手误差为 0，但 3s 开始踏步后 3.5s 跳到约 `413 mm / 98 deg`，仍然摔倒。
- 只启用 `OPENLOONG_T5_FORWARD_PALM_UP=1`、不启用 6-DoF 手任务也会在 5.6s 左右摔倒。

结论：第一层根因不是锁定时机或 SO(3) 姿态误差，而是 walk 分支的 `HandTrackJoints` 仍把手臂拉回旧摆臂目标；前平举初始姿态在切步时被突然改写，破坏稳定性。

### 10.2 源码改动

- `fillWalkHandTrackTask()` 在 `OPENLOONG_T5_FORWARD_PALM_UP=1` 时锁定当前 14 维手臂姿态，打印 `[T5-WALK-ARM-LOCK]`，避免进入 walk 后被拉回旧摆臂姿态。
- `fillWalkHandTrackTask()` 入参增加 `hd_r_rot_cur_W`，为 walk 分支提供右手当前姿态。
- `OPENLOONG_T5_POSTURE=1` 时，walk 分支新增右手 6-DoF 世界位姿保持：
  - 位置 3 维 + SO(3) 姿态 3 维 + 右臂弱正则 7 维 + 左臂姿态保持 7 维。
  - 默认 `OPENLOONG_T5_WALK_LOCK_COUNT=1000`，早于 3s 踏步切入。
  - 默认 walk 权重/增益比 stand 低：优先保证步态稳定，再压手端误差。

## 11. 追加复核：右手手腕是否靠里

用户提出“手腕靠里”后，按任务清单先用 env 实验复核 `elbow_out_bias` 是否是有效主调参。判据采用 `[T5-MJ-INIT]` 中的 base/body frame 几何：

```text
wrist06_pos_L.y <= right_body_pos_L.y
```

右侧外侧定义为更负的 `Y`，因此上述条件成立表示腕关节在正视身体时不比手体更靠内。

### 11.1 实验命令

不改源码，只用站立短 smoke 读取初始化几何：

```bash
OPENLOONG_T1_STAND_ONLY=1 \
OPENLOONG_T5_POSTURE=1 \
OPENLOONG_T5_FORWARD_PALM_UP=1 \
OPENLOONG_T5_ELBOW_OUT_BIAS=<0.25/0.35> \
timeout 18 xvfb-run -a -s "-screen 0 1280x720x24" ./walk_wbc
```

补充测试目标 Y 外移：

```bash
OPENLOONG_T5_INIT_RIGHT_Y=-0.36
OPENLOONG_T5_ELBOW_OUT_BIAS=<0.12/0.30>
```

### 11.3 结论

当前默认 `OPENLOONG_T5_ELBOW_OUT_BIAS=0.12` 已经满足“手腕不比手体更靠内”的日志判据。把 elbow bias 从 `0.12` 增到 `0.25/0.35` 只让 wrist-body 相对差多外移约 `0.2~0.4 mm`，杠杆很弱。

把 `OPENLOONG_T5_INIT_RIGHT_Y` 从 `-0.32` 改到 `-0.36` 会让整只右手整体外移约 `40 mm`，但 wrist-body 相对差仍保持在约 `-7 mm`。因此目标 Y 主要改变全局位置，不解决腕/掌相对几何。

本轮不修改代码默认值。若后续可视上仍觉得“腕部靠里”，下一步更合理的主调参应改为复核末端姿态 / 腕外翻旋转（例如 `OPENLOONG_T5_WRIST_OUT_ROT` 与 palm/thumb/finger 轴定义），而不是继续加 `elbow_out_bias`。
