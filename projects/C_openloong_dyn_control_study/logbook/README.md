# Project C 学习日志

这个目录用于记录 `C_openloong_dyn_control_study` 的复现、调试和学习过程。

推荐用途：

- `daily/`：每日记录，关注当天做了什么、遇到什么问题、下一步是什么。
- `weekly/`：每周总结，关注本周主线进展、关键问题、经验沉淀。
- `monthly/`：每月复盘，关注阶段成果、技术链条理解和下月计划。
- `demo_reading/`：按可执行 demo 分组的源码阅读笔记，关注主流程、模块输入输出和后续追踪点。
- `templates/`：日志模板，写新日志时可以复制对应模板。

推荐命名：

```text
daily/YYYY-MM-DD.md
weekly/YYYY-Www.md
monthly/YYYY-MM.md
```

记录原则：

- 先写事实，再写判断。
- 保留命令、路径、日志位置和错误原文。
- 每次复盘都要写清楚“下一步”。
- 对构建、Docker、MuJoCo、Pinocchio 的问题，尽量记录输入、输出和失败点。
