# Roadmap Logbook

这个目录用于记录跨 demo、面向未来动作扩展的规划和能力边界分析。

和 `demo_reading/` 的区别：

```text
demo_reading/  按单个可执行 demo 归档源码阅读笔记（向内理解现有代码）
roadmap/       按未来目标归档规划和差距分析（向外规划扩展路线）
```

记录原则：

- 先写从代码里确认的事实（能力边界），再写判断（缺什么、怎么做）。
- 每份规划都要写清楚目标之间的依赖关系和难度排序。
- 标注每个目标最该参考的外部仓库，避免盲目下载。

当前已建立：

- `running_jump_hurdle_analysis.md`：奔跑 / 边走边跳 / 跨栏三个目标的能力边界与路线分析。
