# E02 Exit Criteria

## E02 Done Means

以下条件全部满足，才能认为 E02 完成：

1. `docs/06_reproduction_roadmap.md` 已升级成长期维护版路线图，而不是只有阶段列表。
2. E00-E06 每一阶段都写清了：
   - 为什么存在
   - 允许做什么
   - 预期产出是什么
   - 停止条件是什么
   - 下一阶段如何接手
3. 管理视角和学习视角都被单独说明。
4. 下一步已明确切到 E03，而不是跳去执行。
5. 没有因为编写 E02 而引入任何运行、安装、下载或上游源码改动。

## E02 Not Done If

- 只是写了阶段名字，没有写阶段边界。
- 把 E03、E04、E05 的内容提前混成一个“大检查”。
- 在 E02 中偷偷加入命令执行、环境安装或 bundle 下载。
- 没有解释“为什么这样排顺序”。
