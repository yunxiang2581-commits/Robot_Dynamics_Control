# E02 Stage Dependencies

## Dependency Chain

`E00 -> E01 -> E02 -> E03 -> E04 -> E05 -> E06`

## Why The Dependencies Are Strict

| Stage | Depends On | Reason |
|---|---|---|
| E01 | E00 | 如果旧方向没清掉，上游审计会被旧目标污染。 |
| E02 | E01 | 没有 E01 的上游地图，就无法合理设计后续阶段。 |
| E03 | E02 | 没有 E02 的阶段边界，资源审计容易滑向下载或执行。 |
| E04 | E03 | 前置条件必须和公开资源需求对齐，否则检查表没有目标。 |
| E05 | E03 + E04 | 命令计划必须同时知道“能用什么资源”和“需要什么执行条件”。 |
| E06 | E00-E05 | 学习报告必须基于完整过程，而不是只看某一个局部步骤。 |

## Practical Interpretation

- E03 之前，不讨论大文件下载。
- E04 之前，不讨论环境修复。
- E05 之前，不讨论执行命令落地。
- E06 之前，不做“已经能复现”之类的总结。
