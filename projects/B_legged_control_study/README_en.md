# B Legged Control Study

> Chinese version: [README.md](README.md)

This is Track B, the `qiayuanl/legged_control` reproduction and breakdown project.

The focus is NMPC, WBC, QP, state estimation, and ROS control. At the current stage, this project only provides skeleton structure and documentation entry points. It does not store the full external repository and does not mix in A-project self-developed code.
