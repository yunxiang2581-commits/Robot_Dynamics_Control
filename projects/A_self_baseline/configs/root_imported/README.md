# configs

当前目录是后续配置文件的占位目录。

准备阶段不写具体参数。后续配置文件应只保存可调参数和路径，不保存大型模型或二进制资源。

| 后续配置 | 目标 | 当前阶段状态 |
| --- | --- | --- |
| `robot.yaml` | 机器人模型路径和关键 frame 名称 | 未创建 |
| `ik.yaml` | DLS-IK 参数 | 未创建 |
| `qp_ik.yaml` | QP-IK 权重和约束 | 未创建 |
| `mujoco_pd.yaml` | MuJoCo PD 参数 | 未创建 |
| `mini_wbc.yaml` | Mini-WBC 权重和力矩限制 | 未创建 |
