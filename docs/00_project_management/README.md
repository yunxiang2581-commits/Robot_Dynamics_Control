# 项目管理文档入口

本目录保存大项目级管理文档，不再保存具体子项目的长期细节设计。A/B/C/D 的 demo 设计、算法说明和 simulator 说明应放到各自 `projects/*/docs/` 中。

## 当前有效文档

| 文档 | 用途 |
|---|---|
| `PROJECT_STATUS.md` | 当前大项目状态 |
| `MAINLINE_TASK_STATUS.md` | 当前主线任务状态 |
| `PROJECT_STRUCTURE.md` | 推荐目录结构和职责边界 |
| `PROJECT_ROADMAP.md` | 从当前状态到第一个视频 demo 的路线 |
| `DOC_PLACEMENT_RULES.md` | Markdown 文档归属规则 |
| `DOC_MIGRATION_CANDIDATES.md` | 后续迁移候选清单 |
| `DOCS_REORGANIZATION_LOG.md` | docs 本轮整理记录 |
| `repo_cleanup/` | 仓库整理方案文档 |
| `final_merge_report.md` | 早期合并记录，暂时保留 |

## 已归档内容

历史 `step*.md` 阶段记录已迁移到：

```text
docs/archive/project_history/
```

这些文件仍保留，用于追溯项目演化，不作为当前执行入口。
